# Sokoban Search Environment for A* Heuristic Exploration

This project is a custom-built **Sokoban game instance** designed to support experimentation with **A\* search** and different heuristic strategies.

Rather than focusing only on gameplay, this project models Sokoban as a **search problem**, implementing the core components required for A\*:

- State representation
- Successor generation
- Cost function design
- Goal-state detection
- Heuristic exploration

---

## Project Goal

The goal of this project is to create a working Sokoban environment for analyzing how **A\*** performs on complex puzzle problems.

Sokoban is well-suited for search because it requires:
- Careful planning
- Efficient state exploration
- Strong heuristic design to avoid deadlocks and unnecessary paths

This project serves as a foundation for:
- Implementing A\* search
- Comparing heuristic performance
- Studying state-space complexity
- Evaluating cost functions

## Search Problem Design

### State Representation
Each state captures:
- Player position
- Box positions
- Static grid layout (walls and goals)

This allows the problem to be explored as a **state-space graph**.

### Successor Function
Valid next states are generated by:
- Moving the player in four directions
- Allowing box pushes only when legal
- Preventing invalid or blocked moves

### Cost Function
The structure supports flexible cost definitions, such as:
- Uniform step cost
- Push-based costs
- Custom weighted strategies

### Goal Test
A state is considered solved when all boxes are placed on goal tiles.

### Heuristics
This project is designed to experiment with different heuristics for A\*, including:
- Manhattan distance (box → goal)
- Greedy matching approximations
- Deadlock-aware heuristics (future work)

---

## Why Sokoban?

Sokoban is a challenging AI problem because:
- The search space grows rapidly
- Incorrect moves can create irreversible deadlocks
- Performance depends heavily on heuristic quality

This makes it ideal for studying **informed search algorithms** like A\*.
